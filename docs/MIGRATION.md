# 核心代码迁移说明

迁入范围为旧本地工作目录 `NDFitter/` 包下全部 24 个 Python 文件。
读取的是工作目录内容，不仅是最后一次 Git 提交，因此保留了已有的未提交代码修改。
旧 `setup.py` 的包安装配置由 `pyproject.toml` 替代；MIT 许可证原样保留。

没有迁入旧 `.git`、数据、模型权重、输出图片、日志、缓存、编辑器设置、
安装生成信息、实验笔记本或包含特定数据集与集群配置的运行脚本。
两个通用启动脚本替代了原有的个人运行入口。

本轮对 Python 代码的修改限于：

1. 将个人目录默认值改为 `data/mlp`，以项目根目录解析训练、加载及输出路径。
2. 将依赖当前工作目录的 MLP 导入改为包导入。
3. 后端改为按需导入，使基础包及路径工具不强制加载所有训练依赖。
4. TensorBoard 输出固定到被忽略的 `outputs/tensorboard/`。
5. 高斯过程命令行显式要求提供数据目录。

训练公式、模型结构和既有研究参数未作重设计。源码语法、路径解析和 Git 隐私防护
有独立验证；完整训练与科学结果复现需要准备依赖环境和本地数据后另行进行。
保留的旧 MLP 评估 CLI 有已知参数不一致，尚未修复。

新仓库只有本次创建的初始历史，不连接旧远端。旧本地目录和旧远端仓库未被修改。
Git 历史使用通用提交身份，但原许可证中的版权署名依然保留。
